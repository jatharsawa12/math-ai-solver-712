MATH AI — CLASS 7–12
Offline PWA, no API key.

IMPORTANT:
A PWA's service worker requires a secure origin (HTTPS) or localhost. ChromeOS cannot install this folder directly as an offline PWA just by opening index.html from Downloads.

EASIEST USE:
1. Extract the ZIP.
2. Put the folder on a simple HTTPS static host (for example a personal web host).
3. Open it in Chrome.
4. Use Chrome's Install button / menu > Install Math AI.
5. After it is installed and cached, the included solver works offline.

The app itself contains no API key and no network call for solving.
